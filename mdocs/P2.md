## 0. 范围说明：P2 先做什么、不做什么

PRD §5.3 的 P2 候选很宽：目录搜索、云同步、隐身模式、无障碍、跳过静音、内容搜索等。当前阶段已确认三个收敛决策：

1. **P2 主线锁定「桌面平台能力补齐」**：优先强化 Desktop-only 差异化，而不是同时铺开发现、隐私、效率多个主题。
2. **macOS Now Playing 纳入 P2，但只做限时 Spike**：产出可行性与 ADR；风险不可控时 macOS 继续 noop 降级，不阻塞 v2.2.0。
3. **交付形态为小步快跑**：本期交付 4～6 个低风险桌面集成项 + Spike 结论，目标发布 `v2.2.0`。

另外，PRD §5.3 提到的「内容搜索（已下载/已订阅集数全文搜索）」已在 P1 收尾后以本地集数标题/描述搜索落地（见 `Feature.md` 6.2），不纳入本期 P2。

## 1. 目标、非目标与成功标准

### 1.1 本期目标

- 让博播在 Windows / macOS / Linux 上更像系统原生桌面媒体应用：可开机自启、可拖拽导入 OPML、可复制分享链接、具备高频右键菜单、macOS 有 Dock 快捷操作。
- 用限时 Spike 明确 macOS Now Playing 的工程成本与风险，避免把 P2 拖成不可控的原生模块工程。
- 全程不破坏 Offline-first / Local-first：本期能力均不依赖产品方服务，失败时静默降级或明确提示。

### 1.2 非目标（本期不做）

- 不做播客目录搜索、热门推荐、搜索结果订阅。
- 不做云盘同步、多设备冲突解决、云备份凭据管理。
- 不做隐身收听模式、跳过静音、下载限速、下载完成自动播放。
- 不做完整无障碍专项、文字稿/摘要展示、稳定/测试双更新渠道。
- 不承诺 macOS Now Playing 一定落地；Spike 结论为高风险时，仅交付 ADR 与 noop 降级。

### 1.3 成功标准

- `v2.2.0` 发布时，P2-1～P2-5 全量交付并可人工验收；P2-6 交付 Spike 结论/ADR，结论为「可实现」时才允许进入实现任务。
- 新增能力不降低现有核心链路质量：订阅浏览、播放、下载、导入导出在断网与在线场景均无回归。
- `Feature.md` 对应条目更新为已实现或补充明确备注；未实现项保留并说明阶段归属。

## 2. 范围与任务候选

### Epic P2-A：桌面集成抛光（本期交付）

| 任务 | 内容 | 优先级 | 规模 | 依赖 |
| ---- | ---- | ------ | ---- | ---- |
| P2-1 开机自启 | 设置页提供「登录时自动启动」开关，默认关闭；按平台写入 Windows Run 键 / macOS Login Items / Linux autostart desktop | 高 | S | 无 |
| P2-2 文件拖拽导入 | 拖拽 `.opml` 文件到窗口即进入现有 OPML 导入预览流程；非法文件给出明确错误且不写脏数据 | 高 | S | 复用 subscription OPML 导入 |
| P2-3 复制链接 / 分享降级 | 播客复制 Feed URL；集数复制原文链接，缺失时回退音频 URL；复制成功给出轻量反馈 | 高 | S | 集数原文链接字段来源需在实施前定案 |
| P2-4 右键上下文菜单 | 首批覆盖输入框剪切/复制/粘贴，以及订阅、集数、播放列表三类高频项操作 | 中 | M | 需先盘点三类列表项的既有动作入口 |
| P2-5 macOS Dock 菜单 | Dock 右键显示播放/暂停/上一集/下一集/显示主窗口；无播放状态时仅显示窗口操作 | 中 | S | 依赖播放状态广播；macOS 人工验收 |

### Epic P2-B：macOS Now Playing 限时 Spike（结论先行）

| 任务 | 内容 | 优先级 | 规模 | 依赖 |
| ---- | ---- | ------ | ---- | ---- |
| P2-6 Now Playing Spike | 用 2～3 天验证 Node-API 原生模块与可行第三方方案，评估打包、CI、签名/公证影响；产出 ADR。若结论为可实现且低风险，再拆实现任务接入 `MediaSessionAdapter`；否则 macOS 保持 noop 降级 | 高 | S（调研） | 独立；结果影响 Feature.md macOS 媒体控件缺口 |

### 2.1 明确不进入本期

播客目录搜索、热门推荐、云同步、隐身模式、跳过静音、下载限速、下载完成自动播放、完整无障碍、文字稿/摘要、稳定/测试双渠道，均保留在后续 P2.5/P3 或单独专项中评审。

### 2.2 依赖关系

```text
P2-1 开机自启 ─┐
P2-2 拖拽导入 ─┼─ 可并行
P2-3 复制链接 ─┘
P2-4 右键菜单：依赖订阅/集数/播放列表既有动作入口盘点
P2-5 Dock 菜单：依赖播放状态广播（播放中才显示媒体控制项）
P2-6 Now Playing Spike：独立调研；结论为可实现时再排实现任务
```

## 3. 架构边界与实现约束

- **平台差异只进适配层**：开机自启、Dock 菜单、右键菜单、剪贴板/分享降级、macOS Now Playing 均收敛到 `src/main/infra/*` 适配器；业务 service 与渲染进程组件不得写 `process.platform` 分支。
- **IPC 契约先行**：新增能力必须先扩展 `src/shared/ipc-contract.ts`（zod schema + 通道名），再进 preload 白名单与 `src/main/ipc/handlers.ts`；渲染进程只经对应 `features/*/api.ts` 调用。
- **Feature-first 放置**：开机自启归设置/系统能力入口；拖拽导入归 `subscription`；复制链接归 `subscription`/`episode` 的分享动作；右键菜单与 Dock 菜单由 `app` 与对应 feature 编排，不把平台逻辑散进业务组件。
- **Offline / Local-first**：本期不新增任何产品方服务或强制网络依赖；拖拽导入复用本地 OPML 解析；复制链接只使用本地已保存的 Feed/集数字段；Now Playing 失败必须 noop 降级，不影响播放。
- **数据与设置**：优先复用现有 settings；若集数「原文链接」当前模型缺失，P2-3 实施时只能新增可空字段或明确回退到 `audioUrl`，不做破坏性 schema 变更。
- **安全边界**：拖拽导入校验扩展名、文件大小与解析错误；右键菜单不暴露任意 IPC；复制/打开外部链接需用户显式触发，不做静默 `openExternal`。

## 4. 验收与测试策略

### 4.1 完成定义（Definition of Done）

1. P2-1～P2-5 全部交付；P2-6 交付 Spike 结论/ADR，且结论为「可实现」时才允许新增实现任务。
2. 每项功能有可自动化验收的测试或明确人工验收记录；CI 的 lint、boundaries、typecheck、test、build、E2E 全绿。
3. 断网环境下核心旅程（浏览已订阅、播放已下载、管理播放列表、导入导出）无回归。
4. `Feature.md` 对应条目更新；macOS Now Playing 若未实现，保留未勾选并写明「P2 Spike 后仍降级」。
5. 发布 `v2.2.0`。

### 4.2 自动化测试要求

| 任务 | 自动化验收重点 |
| ---- | -------------- |
| P2-1 开机自启 | 适配器单测：三平台命令/注册路径 mock；设置项持久化；不支持平台降级 |
| P2-2 拖拽导入 | 组件测试：drop `.opml` 触发导入预览；非法文件报错；复用 OPML service 的集成测试不回归 |
| P2-3 复制链接 | 纯函数测试：播客/集数链接取值与回退；组件测试：复制成功反馈 |
| P2-4 右键菜单 | 组件测试：输入框菜单与三类列表项菜单触发既有 action；不出现未接线菜单项 |
| P2-5 Dock 菜单 | 主进程单测：菜单模板随播放态变化；命令映射到既有播放控制 |
| P2-6 Spike | 报告验收；若实现，补 adapter 单测与 noop 降级测试 |

### 4.3 人工验收要求

- 三平台签收：开机自启开关、拖拽导入、右键菜单。
- macOS 额外签收：Dock 菜单；若 Now Playing 进入实现，签收控制中心元数据与播放/暂停/切集。
- Windows/Linux 若平台能力不支持（如部分 Linux 发行版自启或托盘差异），验收「降级提示/隐藏」而不是强制可用。

## 5. 风险与应对

| 风险 | 说明 | 应对 |
| ---- | ---- | ---- |
| macOS Now Playing 原生模块成本 | Node-API 模块涉及编译、签名/公证、macOS CI，维护成本最高 | 限时 Spike + ADR；高风险则 noop 降级，不进入 v2.2.0 实现 |
| Linux 桌面能力差异 | autostart、托盘、Dock 类能力在不同发行版/桌面环境表现不一致 | 适配层检测能力，失败时隐藏或提示；不阻塞主链路 |
| 右键菜单范围膨胀 | 上下文菜单容易蔓延到所有列表与所有操作 | 本期只覆盖输入框 + 订阅/集数/播放列表首批高频项 |
| 拖拽导入安全 | 伪扩展名、大文件、畸形 XML 可能造成卡顿或脏数据 | 校验扩展名/大小；解析失败不写库；复用现有导入预览 |
| 分享语义不清 | Electron 无跨平台原生分享面板 | 本期只做「复制链接」降级；原生分享面板另立专项 |
