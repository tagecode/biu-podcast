## 0. 范围说明：P2 之后先做什么、不做什么

P2 主线已锁定并发布：开机自启、拖拽导入、复制链接、右键菜单、Dock 菜单、Now Playing Spike。PRD §5.3 里仍有大量增强候选（目录搜索、云同步、隐身模式、完整无障碍、跳过静音、文件夹等）。当前阶段确认三个收敛决策：

1. **继续「小步快跑」**：本期交付 4～7 个可独立验收的本地能力，目标发布 `v2.3.0`，不把 P2.5 做成「剩下的 P2 全做完」。
2. **主线锁定 Local-first / 不依赖产品方服务**：数据、设置、播放增强全部落在本机 SQLite / settings / 渲染进程；失败时静默降级或明确提示。不引入账号、目录 API、云备份、遥测。
3. **先还 P2 的技术债，再加新能力**：P2-2/P2-3 有三处「已勾选但体验未对齐」的缺口（见 §2 Epic A），必须进本期，避免债务滚入 P3。

macOS Now Playing **不进入本期**。Spike 结论仍是 `defer-with-noop`；除非原生模块风险显著下降，否则继续保持 macOS 媒体会话降级。

## 1. 目标、非目标与成功标准

### 1.1 本期目标

- 把 P2 已宣称但未对齐的导入/分享体验补齐：OPML 先预览再写入、刷新回填集数原文链接、右键复制也有成功反馈。
- 让订阅列表可按**本机文件夹/分类**整理；OPML 嵌套分类在导入时被消费、导出时被还原（解析层 `opml.ts` 已产出 `categories[]`，当前导入丢弃）。
- 播放器提供可选的**跳过静音片段**（默认关闭，不改音频文件）。
- 日期/数字格式跟随当前界面语言；主路径可用键盘走完，关键图标按钮有可访问名称。
- 全程不破坏 Offline-first / Local-first：断网可浏览已订阅、播放已下载、管理文件夹与播放列表。

### 1.2 非目标（本期不做）

- 不做播客目录搜索、热门推荐、搜索结果订阅、任何产品方 HTTP API。
- 不做云盘同步、多设备冲突解决、云备份、账号体系。
- 不做隐身收听模式、下载限速、下载完成自动播放、默认下载质量设置页。
- 不做完整无障碍专项（三平台读屏认证、系统可访问性 API 深度适配）；不做独立界面缩放专项（`fontScale` 已有）。
- 不做单列/网格视图切换、文字稿/摘要、稳定/测试双更新渠道。
- 不重开 macOS Now Playing 实现；不把 P2-6 的 noop 改成「半成品原生模块」。

### 1.3 成功标准

- `v2.3.0` 发布时，P2.5-1～P2.5-7 全量交付并可人工验收；若 P2.5-5（跳过静音）在实施计划时间盒内无法稳定，允许按 P2-6 同款 **defer-with-documented-reason** 降级，不阻断版本，但必须留下 ADR 与 Feature.md 备注。
- 新增能力不降低现有核心链路质量：订阅、播放、下载、导入导出在断网与在线场景均无回归。
- `Feature.md` 对应条目更新为已实现或补充明确备注（阶段归属 / 降级原因）。

## 2. 范围与任务候选

### Epic P2.5-A：P2 遗留小修补（必须先做）

对照 P2.md 原文与 `v2.2.0` 实现，下列三项已勾选但行为未对齐。规模均小，优先于新功能。

| 任务 | 内容 | 优先级 | 规模 | 依赖 |
| ---- | ---- | ------ | ---- | ---- |
| P2.5-1 OPML 导入预览 | 设置页「导入 OPML」与窗口拖拽 `.opml` **共用**「先解析、列出将导入的源、用户确认后再写入」流程；取消不写库；非法文件明确报错。当前两者都是解析后立即 `subscribe` | 高 | S | 复用 `parseOpml`；新增 preview IPC，导入 IPC 保持写入语义 |
| P2.5-2 刷新回填 `episode.link` | `EpisodeRepository.insertMany` 对已存在（guid/audioUrl 命中）的集数目前直接 `continue`，导致 P2 上线前入库的旧集永远拿不到原文链接。刷新时应在**不覆盖用户状态**的前提下，回填空的 `link`（及空的 `chaptersUrl`） | 高 | S | 现有 refresh / insertMany |
| P2.5-3 右键复制成功反馈 | 详情页 `CopyLinkButton` 已有「已复制」；订阅/集数**上下文菜单**的复制链接仍无反馈。与按钮共用同一轻量确认（文案/时序一致） | 中 | S | P2-3 / P2-4 已有复制动作 |

顺手约束（不单独立项，实施 P2.5-1 时处理）：Linux `.desktop` `Exec=` 路径含空格时需加引号（P2-1 人工验收已知边角）。

### Epic P2.5-B：本机订阅文件夹

| 任务 | 内容 | 优先级 | 规模 | 依赖 |
| ---- | ---- | ------ | ---- | ---- |
| P2.5-4 播客文件夹/分类 | 一个播客只属于**一个**分类（可空 = 未分类）。支持创建 / 重命名 / 删除分类、将播客移入/移出；订阅列表按分类分组展示并可筛选。OPML 导入：消费已解析的 `categories[]`，用完整路径（`/` 连接）作为分类名，不存在则自动创建。OPML 导出：按分类嵌套 `<outline>`，不再扁平丢分类 | 高 | M | P2.5-1 的 preview 应展示将创建的分类；schema 增可空字段或独立 folders 表 |

**定案（写进范围，实施计划不得再 bicameral）**：

- 不做多分类、不做嵌套树 UI（OPML 多层路径压成「技术 / 前端」一条分类名）。
- 删除分类：播客回到「未分类」，不级联退订。
- 分类数据只存本机；不与任何远程目录对齐。

### Epic P2.5-C：本机播放增强

| 任务 | 内容 | 优先级 | 规模 | 依赖 |
| ---- | ---- | ------ | ---- | ---- |
| P2.5-5 跳过静音片段 | 设置页播放行为增加开关，**默认关闭**。开启后，播放过程中检测持续低于阈值的静音并跳过；不改写、不重新编码本地文件；CPU/误跳过高则允许用户一键关闭。失败（无 Web Audio、解码受限）时静默退回普通播放 | 中 | M | 现有 `PlayerShell` / audio 元素；settings 持久化 |

**定案**：

- 实时检测，不做整集预扫描、不落库「静音区间」。
- 默认阈值与最短静音时长在实施计划里给出可测常量（建议起点：RMS 阈值 + ≥1.5s 才跳，跳后留 200ms 余量），并可用设置微调或至少提供开/关。
- 若时间盒内无法在三平台（含本地文件 / http(s) 音频）稳定，走 defer，不带半残开关上线。

### Epic P2.5-D：本地化与无障碍切片

| 任务 | 内容 | 优先级 | 规模 | 依赖 |
| ---- | ---- | ------ | ---- | ---- |
| P2.5-6 日期/时间/数字本地化 | `formatDate` 等目前写死 `zh-CN`。改为跟随当前 i18n 语言（`zh` → `zh-CN`，`en` → `en-US`，后续语言按同一表扩展）。数字/文件大小若对用户可见，同样跟语言，不跟系统区域强制覆盖手动选中的界面语言 | 中 | S | `src/renderer/src/lib/format.ts` + 调用点 |
| P2.5-7 键盘与可访问名称 | 主路径可用 Tab / Enter / Esc 走完：添加订阅、订阅列表、集数列表、迷你播放器核心控制、设置开关。图标按钮与无可见文本的控件提供 `aria-label`（或已有可见标签）。**不做** VoiceOver/Narrator/Orca 认证，**不做**新的缩放体系 | 中 | M | 现有 Radix 组件与播放快捷键 |

## 3. 架构边界与实现约束

沿用 P2 / P1.5 约定，本期额外强调：

- **平台差异只进适配层**：`process.platform` 仍只允许出现在 `src/main/infra/*`。跳过静音若受平台音频限制，在播放适配/渲染侧做能力检测后降级，不在业务 service 里写平台分支。
- **IPC 契约先行**：P2.5-1 preview、P2.5-4 文件夹 CRUD、P2.5-5 设置项，必须先扩展 `src/shared/ipc-contract.ts`（zod + 通道名），再 preload 白名单与 `handlers.ts`；渲染进程只经 `features/*/api.ts`。
- **Feature-first 放置**：文件夹归 `subscription`；跳过静音归 `playback` + settings；日期格式归 renderer `lib/format`；OPML preview 归 `subscription`，拖拽仍由 `app` 编排、不把解析逻辑塞进 `AppShell`。
- **Offline / Local-first**：不新增产品方服务、不强制在线。文件夹与设置断网可用。跳过静音只处理当前正在播放的本地/已缓冲音频，不上传波形、不请求云端分析。
- **数据与设置**：
  - 文件夹：优先 `podcasts` 上可空 `folder`/`folderId` + 可选 `folders` 表；迁移必须向后兼容；`data-portability` 导出/导入包含分类。
  - 跳过静音：复用 settings 键，默认 `false`。
  - `insertMany` 回填只更新「当前为空」的 `link` / `chaptersUrl`，不得重置 `isPlayed`、进度、下载状态。
- **安全边界**：OPML preview 与导入继续校验扩展名、大小、解析错误；确认前不写库。右键菜单不新增任意 IPC。分类名做长度与非法字符约束，防止异常 OPML 撑爆 UI。

## 4. 验收与测试策略

### 4.1 完成定义（Definition of Done）

1. P2.5-1～P2.5-4、P2.5-6、P2.5-7 全部交付；P2.5-5 交付实现 **或** 与 P2-6 同规格的 defer ADR（含复现结论与复开条件）。
2. 每项有可自动化验收的测试或明确人工验收记录；CI 的 lint、boundaries、typecheck、test、build、E2E 全绿。
3. 断网环境下核心旅程（浏览已订阅、播放已下载、管理分类与播放列表、导入导出）无回归。
4. `Feature.md` 对应条目更新；未做项保留并写明阶段归属。
5. 发布 `v2.3.0`。CHANGELOG 区分「P2 修补」与「P2.5 新能力」。
6. 三平台人工签收清单（建议 `mdocs/P2.5-Acceptance.md`，发布后补签不阻断版本，同 P2）。

### 4.2 自动化测试要求

| 任务 | 自动化验收重点 |
| ---- | -------------- |
| P2.5-1 OPML 预览 | 解析不写库；确认后才 subscribe；取消零写入；拖拽与设置入口走同一 preview 契约；非法扩展名/畸形 XML 报错 |
| P2.5-2 link 回填 | `insertMany`：已存在且 `link` 为空时写入新 link；已有 link 不覆盖；`isPlayed`/进度不变；新集仍插入 |
| P2.5-3 复制反馈 | 上下文菜单复制后出现与按钮一致的成功态；无链接时的回退仍成立 |
| P2.5-4 文件夹 | repository：分配/重命名/删除后播客归属；OPML 导入带 `categories` 建分类；导出嵌套；未分类分组 |
| P2.5-5 跳过静音 | 设置默认关；开启后对「超阈值静音片段」触发 seek 的纯函数/假音频测试；能力缺失时不抛未捕获错误 |
| P2.5-6 日期本地化 | `formatDate` 在 `zh`/`en` 下输出不同 locale；无回归的空值/`--` |
| P2.5-7 键盘 a11y | 组件测试：主路径控件可 focus；图标按钮有 accessible name；不引入无法聚焦的新交互 |

### 4.3 人工验收要求

- 三平台：OPML 拖拽预览 → 确认导入；刷新后旧集「复制链接」变为节目页而非音频直链（有 link 的源）。
- 文件夹：创建/改名/删除、拖入或菜单移动播客、导出后再导入分类仍在。
- 跳过静音（若交付）：选一集含明显广告静音的节目，开启后能跳过且语音不被误切；关闭后恢复。
- 切换中/英：列表日期格式变化。
- 键盘：不使用鼠标完成「添加订阅 → 打开一集 → 播放/暂停」。

## 5. 风险与应对

| 风险 | 说明 | 应对 |
| ---- | ---- | ---- |
| 跳过静音误跳/耗电 | 轻声口播、ASMR、现场录音易被当成静音；Analyser 持续跑 CPU | 默认关；最短时长门槛；时间盒；不稳则 defer，不带半残开关 |
| 文件夹 UI 范围膨胀 | 嵌套树、多分类、拖拽排序容易做成 P3 体量 | 锁死「单分类 + 扁平分组」；OPML 多层只压成路径字符串 |
| OPML preview 与现有立即导入行为差 | 用户已习惯拖入即导入 | preview 默认选中全部；Enter/主按钮确认；条目少时也可快速确认 |
| `insertMany` 回填写错字段 | 误更新进度/已听状态 | 白名单只更新空的 `link`/`chaptersUrl`；回归测试锁用户字段 |
| a11y 切片变成读屏专项 | Tab 顺序与 ARIA 易无限扩张 | 只覆盖 §2 列出的主路径；读屏认证明确非目标 |
