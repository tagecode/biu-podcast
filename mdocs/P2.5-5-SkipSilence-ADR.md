# ADR: Defer skip-silence playback toggle (P2.5-5)

## Status

Accepted for `v2.3.0`. The pure detector lives in the repo; the settings toggle does not ship.

## Context

P2.5 specified optional skip-silence on the in-process `HTMLAudioElement`: a Web Audio `AnalyserNode` reads RMS, and a small state machine seeks over long quiet gaps. Default off; no file rewrite; no persisted silence ranges.

`HTMLMediaElement.createMediaElementSource` can be connected only once per element. If the graph omits `destination`, playback goes silent. CORS / already-hooked sources throw. Those failures are session-specific and easy to confuse with a working “on” checkbox.

## Decision

Ship the pure functions and tests only:

- `src/renderer/src/features/playback/lib/skip-silence.ts`
- `src/renderer/src/features/playback/lib/skip-silence.test.ts`

Do **not** add `AppSettings.skipSilenceEnabled` or a Settings checkbox until the analyser is proven on real episodes.

## Evidence in this timebox

- Reducer cases are covered: short dip does not seek; ≥1.5s silence hops forward; speech after skip pads back 200ms; NaN / empty buffer does not seek; seek is clamped to `duration - 0.25s`.
- No Windows / macOS / local-file listening pass was completed. `MediaElementSource` was not attached to the live player, so mute / double-play / chopped-speech symptoms were not observed — they were not ruled out either.

## Reopen when

1. `createMediaElementSource(getAudio())` succeeds for both a local downloaded file and a remote stream on Windows and macOS.
2. `source → analyser → destination` keeps audible playback (no mute, no second element).
3. A long real silence hops forward; the following speech is not chopped (padding seek is acceptable).
4. Connecting twice (or CORS throw) logs once and leaves the toggle off for that session.

If (1)–(3) hold, add `skipSilenceEnabled` (default `false`) next to `openFullPlayerDefault` and gate the rAF loop on the flag. If `MediaElementSource` remains unreliable, decode via `OfflineAudioContext` as a later experiment — do not half-wire a settings control.
