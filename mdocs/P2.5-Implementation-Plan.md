# BiuPodcast P2.5 Local-first Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship `v2.3.0` as a small Local-first release: close three P2 UX gaps (OPML preview, episode link backfill, context-menu copy feedback), then add on-device folders, optional skip-silence, locale-aware dates, and a keyboard/accessible-name slice — with no product-side services.

**Architecture:** IPC still goes through `src/shared/ipc-contract.ts` + preload whitelist. Folders live in SQLite (`folders` + `podcasts.folder_id`) under the subscription feature. OPML preview is parse-only; confirmed items are a second write IPC. Skip-silence is a renderer Web Audio analyser on the existing `HTMLAudioElement`, default off. Date formatting reads `i18n.language`. Platform branching stays in `src/main/infra/*`.

**Tech Stack:** Electron 39, React 19, TypeScript, Zustand, better-sqlite3 + Drizzle, electron-store, i18next, Vitest + Testing Library, Playwright.

**Spec:** [`mdocs/P2.5.md`](./P2.5.md). Target version `v2.3.0`. Skip-silence (Task 6) is the only item allowed to defer with an ADR.

## Global Constraints

- Electron `^39.2.6`; Node types `^22`; package manager `pnpm@10.11.0`; do not add a second package manager lockfile.
- Platform branching is allowed only under `src/main/infra/*`; renderer and feature services must not import `process.platform`.
- Every renderer → main capability must be declared in `src/shared/ipc-contract.ts` with a zod schema, exposed in `src/preload/index.ts`, and mirrored in `src/preload/index.d.ts`.
- User-visible renderer strings go in `src/renderer/src/locales/zh.ts` and `src/renderer/src/locales/en.ts`; main-process strings go in `src/main/infra/i18n/index.ts`.
- Offline-first / Local-first: no product-side HTTP APIs, no cloud, no account. Folders, OPML, settings, and skip-silence analysis stay on-device.
- `insertMany` backfill may only write empty `link` / `chaptersUrl`; never `isPlayed`, progress, or download fields.
- Folders: one folder per podcast; delete folder sets `folder_id` null (unsubscribe is not cascaded). OPML category path is joined with `' / '` (full path, max 80 chars).
- Skip-silence: default `false`; no file rewrite; no persisted silence ranges; no settings slider in this version. Timebox 2–3 days; if unstable, ADR + no half-built toggle.
- Each task ends with its focused tests green plus `pnpm run lint` and `pnpm run typecheck` before commit.

```ts
// src/renderer/src/lib/format.ts
export function dateLocaleFromLang(lang: string | undefined): 'zh-CN' | 'en-US' {
  return lang?.toLowerCase().startsWith('en') ? 'en-US' : 'zh-CN'
}

export function formatDate(timestamp: number, lang?: string): string {
  return new Intl.DateTimeFormat(dateLocaleFromLang(lang), {
    year: 'numeric',
    month: '2-digit',
    day: '2-digit'
  }).format(new Date(timestamp))
}

export function formatFileSize(bytes: number | null, lang?: string): string {
  if (!bytes || bytes <= 0) return '--'
  const locale = dateLocaleFromLang(lang)
  if (bytes < 1024 * 1024) {
    return `${new Intl.NumberFormat(locale).format(Math.round(bytes / 1024))} KB`
  }
  return `${new Intl.NumberFormat(locale).format(Number((bytes / (1024 * 1024)).toFixed(0)))} MB`
}
```

```ts
export const COPIED_MS = 2000

const listeners = new Set<() => void>()

export function notifyCopied(): void {
  for (const listener of listeners) listener()
}

export function subscribeCopied(listener: () => void): () => void {
  listeners.add(listener)
  return () => {
    listeners.delete(listener)
  }
}
```

```ts
export const FOLDER_NAME_MAX = 80

export function folderNameFromCategories(categories: string[]): string | null {
  const parts = categories.map((part) => part.trim()).filter(Boolean)
  if (parts.length === 0) return null
  return parts.join(' / ').slice(0, FOLDER_NAME_MAX)
}

export function quoteDesktopExec(execPath: string): string {
  if (!/[\s"]/.test(execPath)) return execPath
  return `"${execPath.replace(/\\/g, '\\\\').replace(/"/g, '\\"')}"`
}
```

**Interfaces:**

```ts
export const SKIP_SILENCE = {
  rmsThreshold: 0.015,
  minSilenceMs: 1500,
  paddingMs: 200,
  hopMs: 1000
} as const

export function rmsFromByteTimeDomain(samples: Uint8Array): number

export type SkipSilencePhase = 'idle' | 'accumulating' | 'skipping'

export function reduceSkipSilence(
  state: { phase: SkipSilencePhase; silentMs: number },
  input: { rms: number; dtMs: number; currentTimeSec: number; durationSec: number }
): { phase: SkipSilencePhase; silentMs: number; seekToSec: number | null }
```

State machine:
- `idle` + rms < threshold → `accumulating`, add `dtMs`
- `accumulating` + rms ≥ threshold → `idle`, `silentMs = 0`
- `accumulating` + `silentMs >= minSilenceMs` → `skipping`, `seekToSec = min(current + hopMs/1000, duration)`
- `skipping` + rms < threshold → keep hopping
- `skipping` + rms ≥ threshold → `seekToSec = max(0, current - paddingMs/1000)`, then `idle`

Never seek past `duration - 0.25s`. Never throw.

Web Audio wiring (only if `skipSilenceEnabled`):
- One `AudioContext` + `createMediaElementSource(getAudio())` for the process lifetime. Connecting twice throws — cache the source.
- `source → analyser → destination` (required, or playback goes silent).
- On `play`, `audioContext.resume()`.
- If `createMediaElementSource` throws (CORS / already hooked): log once, treat as unsupported for this session, do **not** show a broken toggle as “on”.
